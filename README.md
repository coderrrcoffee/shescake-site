# She’s cake — сайт-витрина

Готовая версия сайта для салона тортов и кофейни **She’s cake** (Мытищи).
Заказ собирается на сайте и уходит готовым текстом в Telegram
**@shescake_coffee** — без CRM, оплаты и базы данных.

## Ссылки

- Сайт: https://coderrrcoffee.github.io/shescake-site/
- CMS: https://app.pagescms.org/coderrrcoffee/shescake-site
- Инструкция для клиента: [CMS.md](CMS.md)
- Канал: https://t.me/shescakeru

## Что внутри

- 10 карточек: бенто, торты, капкейки и муссовое сердце;
- категории и корзина;
- самовывоз: дата, время, адрес;
- расчёт суммы и общего веса;
- готовый текст заказа в Telegram;
- мобильная версия;
- политика конфиденциальности;
- каталог в `data/catalog.json` и схема Pages CMS.

## Что проверить перед запуском

Цены, веса и фото собраны из открытых источников — сайта `shescake.ru`
и Telegram-канала. Перед продажей клиенту их нужно подтвердить:

- бенто — от 2 000 ₽;
- торты — от 6 200 ₽ за 2 кг;
- капкейки — 1 100 / 2 200 ₽;
- муссовое сердце — 2 200 ₽;
- самовывоз — Институтская, 6, 9:00–20:00;
- вторая кофейня — Мира, 35, 9:00–21:00.

## Структура

```
index.html          главная
config.js           бренд, контакты, тексты, самовывоз
data/catalog.json   товары
.pages.yml          схема Pages CMS
assets/photos/      фото
privacy.html        политика
```

## Деплой

Vercel: Framework Preset **Other**, Build Command пустой, Output Directory `.`.
GitHub Pages уже включён. После изменений в `main` сайт обновляется сам.

## CMS

Клиента приглашают по email в Pages CMS; GitHub ему не нужен.
Он видит раздел **«Витрина»**, меняет карточки и фото, не трогая код.
